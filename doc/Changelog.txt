LITESOUT for OS/2 -- Changelog
================================

Version 1.2  (2026-10-13)
--------------------------
  - New Options > Key Mapping... dialog (mouse only): choose the mouse button
    that hits a block (left button by default); the other buttons are
    ignored. The choice is saved in litesout.cfg (older files keep working)
    and the dialog is translated in all six languages
  - Frame Controls (Ctrl+F) rewritten: the title bar, system menu, minimize
    button and menu are shown again explicitly when the controls come back,
    the window keeps its client area (it shrinks and grows around it) and
    the check mark follows the state
  - About dialog, BLDLEVEL string and documentation updated to version 1.2

Version 1.1  (2026-09-29)
--------------------------
  - 32-bit OS/2 Presentation Manager port from Borland OWL original
  - Plain C, OpenWatcom 2.0, no C++ or OWL dependency
  - 6-language runtime switching: EN, ES, NL, DE, FR, IT
  - Keyboard shortcuts: Ctrl+N (New), Ctrl+T (Top Ten), Ctrl+F (Frame),
    Ctrl+X (Exit)
  - Binary settings file (litesout.cfg): saves difficulty, language,
    and 20 high-score entries
  - Top Ten Scores dialog with separate Easy / Hard tables
  - Enter Name dialog when a new high score is achieved
  - Frame Controls toggle (hides title bar and menu bar)
  - Hard mode: cycling 3-state blocks; Easy mode: simple on/off
  - Scramble animation on New Game using scramble cursors
  - PM coordinate system Y-flip applied throughout
  - BLDLEVEL string embedded in executable
  - BSD 3-Clause License applied to 32-bit port


Version 1.0  (1997)
--------------------
  - Original release by Herbert Bushong
  - Borland OWL / 16-bit / 32-bit Borland C++ build
  - Easy and Hard mode
  - Top Ten scores, Enter Name dialog
  - Scramble animation
